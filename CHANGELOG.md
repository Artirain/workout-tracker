# Changelog

## 2026-04-07 — Initial Release

### Added
- Project setup with GitHub Pages deployment
- Design system: dark theme, glassmorphism, mobile-first responsive
- Workout recording: exercise selector, sets (weight × reps), save to localStorage
- Dashboard: today's stats, water tracker (2000ml goal), recent workouts
- History: all workouts grouped by date, filters, delete
- Progress: Chart.js graphs (max weight, volume, reps over time), personal records
- Data layer: localStorage + JSON file sync for future Telegram integration
- Default exercises: Жим лёжа, Присед, Подтягивания, Бабочка
- Custom exercise support
